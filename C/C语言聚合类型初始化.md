你看到的这段代码实际上用到了 **C 语言聚合类型（aggregate）初始化**，包括：

- 数组初始化
- 结构体初始化
- 嵌套结构体初始化
- 默认初始化（未写出的成员自动补 0）

PostgreSQL 的 GUC 定义大量使用这种写法。下面从基础讲起。

聚合类型的概念见这篇文章：[C语言聚合类型概念.md](C语言聚合类型概念.md)

# 一、数组初始化

假设有

```
int a[5];
```

最普通的初始化

```
int a[5] = {1, 2, 3, 4, 5};
```

内存

```
a
+---+---+---+---+---+
| 1 | 2 | 3 | 4 | 5 |
+---+---+---+---+---+
```

------

如果初始化元素不足

```
int a[5] = {1, 2};
```

等价于

```
int a[5] = {1, 2, 0, 0, 0};
```

C 规定：

> 剩余元素全部初始化为 0。

------

## **长度也可以自动推导**

```
int a[] = {1,2,3};
```

等价于

```
int a[3];
```

------

二维数组

```
int a[2][3] = {
    {1,2,3},
    {4,5,6}
};
```

------

# 二、结构体初始化

例如

```
struct Person
{
    char *name;
    int age;
};
```

初始化

```
struct Person p =
{
    "Tom",
    18
};
```

对应关系就是

```
第一个成员 -> name
第二个成员 -> age
```

等价于

```
p.name = "Tom";
p.age = 18;
```

只是初始化发生在创建对象时。

------

# 三、嵌套结构体初始化

例如

```
struct A
{
    int x;
    int y;
};

struct B
{
    struct A a;
    int z;
};
```

初始化

```
struct B b =
{
    {
        1,
        2
    },
    3
};
```

对应关系

```
b
├── a
│    ├── x = 1
│    └── y = 2
└── z = 3
```

------

也可以写成一行

```
struct B b = { {1,2}, 3 };
```

# 四、结构体数组初始化

规则一模一样。只是既是结构体又是数组。

----

个人总结版：

聚合类型初始化，按成员顺序赋值， 后面没有给值的，自动置0.

结构体可嵌套。子对象用花括号隔开。

数组的话，

1. 如果未指定长度，长度可以自动推导。如 int a[] = {1,2,3}; 自动推导长度为 3 
2. 数组每个元素都可以用聚合类型初始化方式进行
